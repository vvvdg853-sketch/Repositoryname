# محلل الشارت - Flutter + Twelve Data

## ما الذي يتضمنه المشروع؟
- واجهة عربية RTL.
- اختيار BTC/USD وETH/USD وSOL/USD وXRP/USD.
- أطر زمنية 1m و5m و15m و1h و4h و1day.
- تحميل الشموع من Twelve Data عبر `/time_series`.
- رسم شموع مخصص.
- حساب RSI(14) وEMA(9/21) وإشارة احتمالية مبسطة.
- تخزين المفتاح محلياً عبر `flutter_secure_storage`.

## التشغيل
1. ثبّت Flutter وAndroid Studio على الكمبيوتر.
2. فك ضغط المشروع.
3. من داخل مجلد المشروع شغّل:
   ```bash
   flutter create .
   flutter pub get
   flutter run
   ```
4. أدخل مفتاح Twelve Data داخل التطبيق من نافذة الربط.

## بناء APK
```bash
flutter build apk --release
```
سيكون الملف عادة في:
`build/app/outputs/flutter-apk/app-release.apk`

## ملاحظات مهمة
- هذا إصدار أولي قابل للتطوير، وليس ملف APK مبنياً.
- لم يُختبر الاتصال بمفتاحك؛ لا ترسل المفتاح في المحادثة.
- مفتاح API المخزن على الهاتف محمي بالتخزين الآمن للنظام لكنه يظل قابلاً للاستخراج من جهاز مخترق أو تطبيق مفكوك. للإصدار التجاري، ضع المفتاح في خادم وسيط خاص بك ولا تضعه في التطبيق.
- توافر الرموز والفواصل الزمنية والبيانات اللحظية يعتمد على اشتراك Twelve Data وحدود رصيد API.
- الإشارة الفنية ليست توصية استثمارية ولا تضمن نتيجة الصفقة.
